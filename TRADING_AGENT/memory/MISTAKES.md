# MISTAKES.md — Error & Rule-Violation Log

> Record process errors so they stop recurring. A mistake here is about
> *process*, independent of whether the trade made money (rule 19: a profitable
> trade can still be a bad decision). Never hide or delete entries.

Loss/error classifications used across the system:
- **STRATEGY LOSS** — valid setup, rules followed, normal variance (not a mistake).
- **EXECUTION ERROR** — chasing, bad fill, late entry, premature exit, order mistake.
- **RISK VIOLATION** — size too large, stop violated, exposure excessive.
- **SYSTEM ERROR** — bad data, connection issue, wrong order state, software bug.
- **BEHAVIORAL ERROR** — revenge, FOMO, trading with no setup, ignoring rules.
- **MARKET REGIME ERROR** — strategy wrong for conditions.
